# Motrix WebExtension

This package contains the cross-browser Motrix WebExtension and its native social-media resolver.

## Contents

- `Motrix WebExtension/Chrome/` — Chrome/Chromium MV3 extension build.
- `Motrix WebExtension/Firefox/` — Firefox MV2 extension build.
- `Motrix Social Resolver/` — Windows and Linux/macOS native resolver installer, including the optional local `cookies.txt` workflow.

## Installation

Install the extension from the browser’s extension management page by loading the matching Chrome or Firefox folder from `Motrix WebExtension/`. Then run the appropriate installer from `Motrix Social Resolver/` once and restart the browser.

Keep any real social-media cookies file private. The included `cookies.txt` is only an empty template; do not share or commit a file containing real cookies.
